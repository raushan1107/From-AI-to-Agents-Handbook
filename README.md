# From AI to Agents — A Practical Learning Journey

**Author: Raushan Ranjan** (sole author credit; no co-author listed).

## Open in VS Code
1. Extract this ZIP.
2. In VS Code choose **File → Open Folder** and select `ai-journey-book`.
3. Install the **Live Server** extension (Ritwick Dey).
4. Right-click `index.html` → **Open with Live Server**.
5. Select chapters from the book homepage.

You can also double-click `index.html` to open it directly in a browser. No Node.js, npm, API key or backend is needed. Google Fonts requires internet; system fonts are used as fallback.
